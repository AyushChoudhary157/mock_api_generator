Mock API Generator

Create a live, public REST API with realistic fake data in seconds. Simulate slow networks and failures, then test it right here.

  • Free

  • Full CRUD

Heads up: mock endpoints are public. Anyone with the URL can read and change the data, so use fake data only.

How it works

From idea to a working endpoint in three steps. No installs, no sign-up.

  1. 1

    Create a project

    Give it a name and get a unique public base URL: /api/v1/<project-id>/<resource>. Your access key lives in your browser, so there is nothing to register.

  2. 2

    Define a resource

    Describe your API in plain English and let AI draft the schema, build it field by field with drag-to-reorder, or import JSON and CSV. Realistic records are generated instantly.

  3. 3

    Copy your endpoint

    Call it from your app, Postman or CI. Add delays, random errors and custom headers, then use the built-in tester and copy ready-made cURL, fetch, axios or Python code.

Endpoint reference

Every resource you create gets the full REST surface below.

MethodPathWhat it does
GET/api/v1/{project}/{resource}List records (paginated, sortable, filterable, searchable)
GET/api/v1/{project}/{resource}/{id}Get one record
POST/api/v1/{project}/{resource}Create a record (JSON body, validated against your schema)
PUT/api/v1/{project}/{resource}/{id}Replace a record
PATCH/api/v1/{project}/{resource}/{id}Update some fields
DELETE/api/v1/{project}/{resource}/{id}Delete a record and return it
GET/api/v1/{project}/{parent}/{id}/{child}One-to-many relation (child has a “ref” field to the parent)

Query parameters

ParameterExampleDescription
page, limit?page=2&limit=20Pagination. Limit is 1–100 (default 10). Totals are in the X-Total-Count header.
sortBy, order?sortBy=price&order=descSort by any schema field, ascending or descending.
field?role=adminExact-match filter on any field. Repeat it for OR.
search?search=janeCase-insensitive search across all fields.
envelope?envelope=trueWrap the list in { data, meta } instead of a bare array.

Frequently asked questions

Is the Mock API Generator really free?

Yes. The free tier includes 5 projects, 10 resources per project, 100 records per resource and 1,000 API requests per project per day. Limits are shown live in the sidebar.

Do I need to create an account?

No. Your projects are linked to a private access key stored in your browser. Open “Access key & backup” in the sidebar to save it, so you can manage your projects on another device.

Can I call the mock API from my frontend app?

Yes. Every endpoint sends open CORS headers, so you can call it from any browser app, Postman, cURL or a CI job.

How do I simulate slow or failing APIs?

Open the Settings tab. You can add a response delay, a random error rate with a custom status code, custom success status codes and custom headers, for one resource or for the whole project.

How long are my projects kept?

Anonymous projects with no activity for 30 days are deleted automatically. You can export your schema and data as JSON at any time.

Is it safe to store real or sensitive data?

No. Mock endpoints are public: anyone who knows a URL can read and change its data. Only use fake or non-sensitive data.

How does the AI feature work?

Describe your API in plain English and the AI proposes resources, fields and relationships. The proposal is validated against a strict JSON schema and you review it before anything is created. Plain CRUD and simple field types always use the built-in generator, which keeps things fast.
